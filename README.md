## Fitur Utama & Teknologi
1. **HTML5 Semantik:** Penggunaan elemen `<header>`, `<main>`, `<section>`, `<article>`, dan `<footer>` secara terstruktur untuk mendukung SEO dan aksesibilitas.

2. **CSS Modern & Responsive Design (RWD):**
   * CSS Variables (`:root`) untuk konsistensi skema warna.
   * Universal reset Box Model (`box-sizing: border-box`).
   * **Flexbox:** Digunakan pada navigasi header dan layout komponen interaktif.
   * **CSS Grid:** Implementasi `grid-template-columns: repeat(auto-fit, minmax(...))` pada galeri kartu materi dan paket kelas.
   * **Media Queries:** Optimasi breakpoint untuk smartphone, tablet, dan desktop.

3. **Optimasi Aset:** Format gambar ringkas (`.webp`) dan ikon berbasis vektor (`.svg`).
